Patent Timeline

Filing to grant, four times over

Seven years from first filing to the most recent grant. Each application was examined and allowed on its own merits.

US 9,990,035 B2 Granted
Filed Mar 2016
Granted Jun 2018

Image Changes Based on Viewer's Gaze

The first patent in the family covers a system that monitors where a viewer is looking and updates the displayed image in response. Using eye-tracking input, the display can shift content, reveal layers, or transition between states based on gaze position and dwell time. The claims cover both the detection method and the image-update logic that responds to it.

Eye Tracking Adaptive Display G06F 3/013
US 10,416,765 B2 Granted
Filed Jun 2018
Granted Sep 2019

Image Changes Based on Viewer's Gaze (Continuation)

A continuation of the original gaze patent, this filing extends the claim set to cover additional scenarios and implementation details not captured in the parent. Continuations let an inventor pursue claim variations while the original patent is in prosecution, and this one was granted just 15 months after filing, a fairly quick turnaround at the USPTO.

Continuation Gaze Detection G06F 3/04845
US 11,016,563 B2 Granted
Filed Sep 2019
Granted May 2021

Image Changes Based on Voice

The third patent takes the same core idea — a display that adapts to viewer input — and applies it to voice. The system detects spoken input and uses it to trigger image transitions or state changes on the display. The claims cover the mapping from audio detection to visual output, which is a distinct modality from gaze but sits in the same conceptual space as the earlier work.

Voice Input Audio-Visual G06F 3/011
US 11,782,507 B2 Granted
Filed Jul 2022
Granted Oct 2023

Image Changes Based on Facial Appearance

The most recent granted patent extends the family into facial recognition as an input channel. The system detects characteristics of the viewer's face and uses them to determine which image to display or how to modify the current one. This brings together computer vision, real-time image processing, and the adaptive display logic established across the earlier patents into a unified system.

Facial Recognition Computer Vision G06F 3/0487

Classification

Where the USPTO filed this work

All four patents fall under cooperative patent classification G06F 3, the subclass for interfaces between users and computers. More specifically, the examiner classified them under detection of eye movements and gesture-based interaction.

G06F 3/013
Recognizing from the eye, e.g. iris or gaze — the core classification for the original gaze-based patents.
G06F 3/011
Detecting the position or movement of a finger, hand, or other body part — covers touch and proximity sensing aspects.
G06F 3/04845
Scrolling or panning — appears in the continuation patent where the gaze interaction drives content scrolling behavior.
G06F 3/0487
Using special purpose keys or input combinations — the USPTO's classification for the multi-modal input claims.
